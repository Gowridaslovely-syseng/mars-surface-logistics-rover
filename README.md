# 🚀 Mars Surface Logistics Rover

> A collaborative model-based systems engineering project exploring the conceptual design of an autonomous rover for cargo transportation on the Martian surface.

---

## Overview

This repository documents my contributions to a graduate group project completed as part of the Master of Engineering in Systems Engineering program at Stevens Institute of Technology.

The objective of the project was to design an autonomous Mars logistics rover capable of transporting cargo between a surface habitat and a Mars lander while operating under challenging environmental conditions including communication delays, rough terrain, dust exposure, and limited maintenance opportunities.

---

## Project Objectives

- Design an autonomous cargo transportation system for Mars
- Develop system requirements and operational concepts
- Apply Model-Based Systems Engineering (MBSE) principles
- Define functional architecture and system interfaces
- Develop verification and validation strategies
